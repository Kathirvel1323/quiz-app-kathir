# Quiz App enhancements

- Ten multiple-choice Flutter questions with one answer per question.
- Each answer reveals correctness and a short explanation.
- Progress indicator, final score, tailored result feedback, and restart.

## Structure

- `lib/main.dart`: question data, quiz state, feedback, and results screen.
- `test/widget_test.dart`: complete quiz and restart flow.

## Demo checklist

1. Answer a question correctly and incorrectly to see both feedback states.
2. Continue through all ten questions and inspect progress.
3. Review the score message and restart the quiz.
